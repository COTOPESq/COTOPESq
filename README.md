| Проект | Что сделал |

## Сети и SOC

| Тема | Что могу объяснить и разобрать |
| --- | --- |
| Сетевые протоколы | Модели OSI и TCP/IP, различия TCP и UDP, установление TCP-соединения и флаги SYN, ACK, FIN и RST. Назначение DNS, DHCP, ARP и NAT. |
| Веб и защищённые соединения | HTTP и HTTPS, заголовки `Host` и `Cookie`, TLS, SNI и SSH. |
| Диагностика сети | `ping` для проверки доступности, `ip a` и `ip route get` для проверки интерфейсов и маршрута, `ss -tulpn` для просмотра слушающих портов, `dig` и `nslookup` для диагностики DNS. |
| Журналы Linux | `journalctl`, поиск событий аутентификации в `/var/log/auth.log`, фильтрация через `grep`, просмотр последних записей через `tail` и истории входов через `last`. |
| Средства защиты | Роль SIEM в сборе и корреляции событий, различия между IDS, IPS и EDR. Базовые понятия Active Directory, MFA и принципа минимальных привилегий. |
| Анализ алертов | Различия между событием, алертом и инцидентом. Проверка индикаторов компрометации (IOC), признаки перебора паролей и password spraying, тактики и техники MITRE ATT&CK, подготовка данных для эскалации. |

> [!TIP]
> **Учебный кейс SOC L1 — серия неудачных входов.** Сопоставляю время, IP-адреса и учётные записи, проверяю, был ли после ошибок успешный вход, и фиксирую связанные события для дальнейшего разбора.
